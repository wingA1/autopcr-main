# AutoPCR 数据中台页面规格文档

> 基于已确认通过的版本，不做额外功能扩展，不改产品方向。

---

## 一、目标

恢复“数据中台页面”到已确认通过的版本。

## 二、强约束

- 不新增独立后端服务
- 不新增独立前端产品页（仍在原 /daily 体系内）
- 不改原有业务链路，只恢复已确认布局与交互
- 先恢复页面结构，再补数据映射，最后做文案修正

## 三、页面布局（桌面端）

主体必须是左右双列：左侧账号栏 + 右侧中台区。

- 左列固定宽度 360px
- 右列自适应填满
- 两列顶对齐，禁止上下堆叠（桌面端）
- 上方空余区域继续保留并用于搜索/欢迎/快捷操作

## 四、左侧区域（账号栏）

从上到下依次为：

1. 账号搜索框
2. 欢迎卡（使用须知、修改密码、注销QQ）
3. 工具卡（清理全部、批量运行、列表/卡片切换、增删账号）
4. 账号卡列表：账号名、最近运行时间、状态、配置/清理/同步/结果

## 五、右侧区域（数据中台）

### 5.1 顶部结构

- 顶部 Tab：总览、任务状态、异常预警
- 右上角主操作按钮：执行清理

### 5.2 总览卡片区字段（必须有）

| 字段名 | 说明 |
|----------|------|
| 昵称 | 角色昵称 |
| 体力 | 当前体力/最大体力 |
| 等级 | 玩家等级 |
| 钻石 | 宝石数量 |
| 玛那 | 金币数量 |
| 扫荡券 | 扫荡券数量 |
| 母猪石 | 女神石数量 |
| 全角色战力 | 所有角色总战力 |
| 已氪体数 | 已恢复体力次数 |
| 数据时间 | 数据同步时间 |
| 清日常时间 | 最近一次清日常时间 |

### 5.3 数据映射

| 页面字段 | 后端字段 | 备注 |
|----------|----------|------|
| 昵称 | nickname 或 alias | 优先显示 nickname |
| 体力 | stamina / stamina_max | 格式：当前/最大 |
| 等级 | level | |
| 钻石 | jewel | free_jewel + jewel |
| 玛那 | mana | gold_id_free + gold_id_pay |
| 扫荡券 | sweep_ticket | 物品ID 23001 |
| 母猪石 | goddess_stone | 物品ID 90005 |
| 全角色战力 | total_power | 所有单位战力求和 |
| 已氪体数 | recover_stamina_count | recover_stamina_exec_count |
| 清日常时间 | daily_clean_time | |
| 数据时间 | 暂无后端字段 | 需新增或使用 daily_clean_time |

## 六、任务状态字段

至少包含：

- 地下城：已完成/未完成
- 深域：已清理/未清理
- 深域讨伐战：未开启/已开启/已完成

### 状态枚举

统一使用以下枚举值：

| 枚举值 | 中文显示 | 颜色 |
|----------|----------|------|
| done | 已完成 | green |
| partial | 部分完成 | yellow |
| pending | 未执行 | gray |
| running | 执行中 | blue |
| failed | 失败 | red |
| not_open | 未开启 | gray |
| skipped | 已跳过 | gray |

### 状态映射

后端返回的中文状态映射到枚举：

| 后端返回 | 枚举值 |
|----------|----------|
| 成功 | done |
| 警告 | partial |
| 错误 | failed |
| 致命 | failed |
| 跳过 | skipped |
| 中止 | partial |

## 七、已确认的修正文案

| 序号 | 修正项 | 修正前 | 修正后 |
|------|--------|--------|--------|
| 1 | 卡片文案 | 清日常 | 清日常时间 |
| 2 | 数据时间空值 | - | 暂无同步数据 |
| 3 | 左侧切换文案 | 列表/卡片 | 账号列表/账号卡片 |
| 4 | 未选账号提示 | （按钮可用） | 执行清理置灰，提示“请先选择账号” |

## 八、验收标准

1. 1920x1080 下为稳定双列，不换行
2. 左右区结构与已确认版本一致
3. 右侧总览字段完整
4. 任务状态能显示“地下城已完成、深域已清理、深域讨伐战未开启”这类结果
5. 上述 4 个修正文案全部生效

---

## 九、执行步骤

### 步骤1：恢复布局骨架

- 恢复为左右双列：左账号栏，右数据中台区
- 桌面端禁止上下堆叠
- 左列宽度 360px，右列 flex:1 自适应

### 步骤2：恢复左侧完整结构

- 搜索框
- 欢迎卡（使用须知、修改密码、注销QQ）
- 工具卡（清理全部、批量运行、列表/卡片切换、增删账号）
- 账号卡列表（账号名、最近运行时间、状态、配置/清理/同步/结果）

### 步骤3：恢复右侧中台结构

- 顶部 Tab：总览/任务状态/异常预警
- 右上按钮：执行清理
- 总览卡片字段全部恢复

### 步骤4：恢复任务状态模块

- 支持地下城、深域、深域讨伐战状态展示
- 状态统一枚举

### 步骤5：应用已确认修正项

- “清日常”改“清日常时间”
- “数据时间”空值显示“暂无同步数据”
- “列表/卡片”改“账号列表/账号卡片”
- 未选账号时“执行清理”置灰并提示“请先选择账号”

### 步骤6：自测并交付

- 分辨率 1920x1080 自测双列稳定
- 切换账号后布局不抖动

- 禁止新增独立产品页面入口
